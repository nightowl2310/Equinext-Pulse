# NSE trading holidays -- one date per line, format YYYY-MM-DD.
# Blank lines, and anything after a '#', are ignored.
#
# ------------------------------------------------------------------------
# WHY THIS FILE MATTERS (it does two jobs now)
# ------------------------------------------------------------------------
# 1. The scraper skips these days instead of asking NSE for a file that
#    doesn't exist.
# 2. analysis.py uses it to work out the REAL F&O expiry date. Expiry is
#    normally Thursday, but if that Thursday is a holiday the expiry moves
#    to the previous trading day -- so a wrong holiday here means a wrong
#    expiry comparison.
#
# ------------------------------------------------------------------------
# HOW THESE DATES WERE CONFIRMED
# ------------------------------------------------------------------------
# Dates marked "[confirmed]" are proven by the downloaded data itself: NSE
# published no participant-OI file that weekday, so no trading happened.
# That is stronger evidence than any published list, and it already caught
# three of my earlier guesses being wrong (Mar 4, May 27 and Jun 25 are all
# real TRADING days -- they must never be listed here).
#
# Dates without "[confirmed]" are fixed-date national holidays that fall
# outside the data we've downloaded so far. They're safe (same date every
# year) but will be confirmed automatically as the archive grows.
#
# Adding a date you're unsure about is the ONE dangerous edit: it makes the
# scraper skip a real trading day. Leaving a holiday OUT is harmless -- the
# download just returns a 404 and is logged as a non-trading day. So when in
# doubt, leave it out.
#
# Official list (to check future dates):
#   https://www.nseindia.com/resources/exchange-communication-holidays
# ------------------------------------------------------------------------
